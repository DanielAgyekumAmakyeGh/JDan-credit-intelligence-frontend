# NPL Management Dashboard

## Overview
A real-time dashboard for monitoring Non-Performing Loans (NPLs) at JDan Financial Analytics. Provides insights into lender performance, loan purpose risk analysis, and real-time loan stacking prevention.

## Features
- Executive Summary with key metrics
- NPL trend analysis with interactive charts
- Lender performance ranking
- Loan purpose default analysis
- Real-time loan stacking prevention check
- Borrower affordability calculator
- Automated alerts for high-risk conditions
